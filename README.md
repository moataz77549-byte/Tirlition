# رتيل | Rateel

Rateel is an Arabic-first Android application for Quranic and Islamic radio streams, recitations, reciters, and audio mushafs.

## Status

The project is under active development. The first milestone establishes the Android foundation, data architecture, offline-first storage, navigation, theming, and test/CI infrastructure. It is **not** a production release.

## Source of truth

This GitHub repository is the single source of truth. Official builds must come from a pushed commit with a clean and traceable Git state.

Detailed architecture and setup notes are added as the foundation is implemented.
