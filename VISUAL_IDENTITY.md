# Rateel visual identity — candidate

The original vector mark is an open listening page with a single sound arc: a compact sign of recitation and listening. It uses a deep teal background `#173F40`, warm ivory strokes `#F8F5E9`, and a restrained brass accent `#D8B984`. The mark sits between 26 and 82 of a 108-unit canvas, inside the adaptive icon safe region. The monochrome layer uses alpha-only white strokes for themed icons. No third-party illustration or font is bundled; Android's system sans type supports Arabic shaping. Compose light/dark roles remain in `Theme.kt`: light primary `#315B55`, dark primary `#9FCFC5`. Spacing and rounded surfaces use Material 3 defaults. Check icon mask, contrast and splash on actual launchers before release; this asset has not passed device visual QA.
